# Sunflower Tools Basic

Public, read-only edition of Sunflower Tools for Sunflower Land. It provides a map overview and ready notifications without automation, game actions, account management, or license logic.

## Install locally

1. Download or clone this repository.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Select **Load unpacked** and choose this repository folder.
4. Open Sunflower Land, click the extension icon, then choose **Connect game**.

## Privacy

The extension reads visible information from an open `sunflower-land.com` tab only to render the overview and schedule local Chrome notifications. It does not require a license server or transmit game data.
